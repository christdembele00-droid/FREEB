# FREEB UI layout

FREEB uses a camera-first interaction model inspired by modern camera/social apps, with an independent visual identity.

## Camera screen
- Full-screen camera preview.
- Top-left: profile entry.
- Top-right: flash, search and chat quick actions.
- Right rail: switch camera, sound, effects, text and gallery.
- Bottom center: capture control.
- Bottom navigation: chats, stories, camera, discover and profile.
- Camera is the default entry destination.

## Interaction
- Camera is always reachable in one tap.
- Bottom navigation keeps the five primary destinations available.
- Camera controls are circular, high-contrast and safe for one-handed use.
- UI overlays avoid covering the capture target.
- The camera preview is independent from business logic and will be connected to Vulkan effects.

## Product rule
Match the interaction density and discoverability of a leading camera-first social application, but do not copy proprietary source code, assets, trademarks or exact branded visual identity.
